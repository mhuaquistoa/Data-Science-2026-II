# Crear un branch paralelo 
Se va al apartado de files, en esa parte se encuentra una zona para añadir branchs, lo cuales sirven como un entorno paralelo al main branch, sirven para reaizar ediciones al repositorio sin cambiar el principal. Para pasar las ediciones del branch paralelo al principal, después de guardar los cambios del commit en el branch paralelo, se tiene que hacer un pull request y después un merge. En el apartado de branches, se va a la opción de view all branches; de ahí se solicita generar un pull request en el apartado de los tres puntos a la derecha del branch paralelo(el dueño del repositorio recibe la notificación y puede decidir si hacer el merge o no)
